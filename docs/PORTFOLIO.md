# 个人站维护

公开首页、作品与履历无需登录，AI 工具入口为 `/studio`，公网须启用账号认证。图片和生成历史仍属于各自账号，不会出现在公开作品集中。

## 内容与资源

- `src/studio/web/portfolio.json`：项目标题、分类、参与角色、状态、介绍、截图、视频和跳转链接。
- `src/studio/web/templates/portfolio_*.html`：首页、分类列表、详情、履历和可打印简历。
- `src/studio/web/static/portfolio/`：用户指定公开的流境、觅境截图，OkChat 三张宣传图及杭麻馆三张横版游戏截图、Trundertrack 三张界面截图、一段原始视频、工作台截图，以及 X 同款头像/横幅。禁止放入数据库、凭据或私人任务输出。
- `src/studio/web/portfolio.py`：已确认社交链接。右下角已配置 GitHub、X、Telegram、微信与邮箱；按用户要求暂不显示 Discord。

流境和觅境暂为「上架中」，只提供真实界面预览。发布后在对应项目的 links 增加真实商店 URL 并更新 status。若以后提供 APK，请先准备实际文件、版本与校验信息，点击仅发起下载，安装由用户在 Android 系统确认，网站不能静默安装。

个人产品与商业参与项目分开归类。没有商店截图的项目采用文字封面，不以生成图冒充真实界面。OkChat 仅描述用户已确认的移动端参与范围，已按用户确认将简历中的 TokChat 统一为 OkChat；心犀仍为独立项目。

视频使用原生播放器、poster、preload=none 与 Range，点击才加载。媒体缓存一天，替换素材内容时建议改文件名避免旧缓存。工作台状态与私有资产 API 不缓存。

## 部署与验证

沿用 FastAPI/Jinja 与原 Compose 项目，不新增前端构建服务。Python wheel 和容器必须包含 portfolio.json、templates 和 static 目录。备份账号数据库与素材后检查无活跃任务，再更新本项目 Web / Worker；不覆盖 runtime.env、data 或其他服务。

确认：首页匿名 200；作品分类与截图大图；流境视频 206 分段播放；手机页面无横向溢出；工具跳登录且保留选项；原账号可读历史，匿名私有 API 为401；主账号不限次数，普通账号原额度不变。

## 身份与交互

`stormg-avatar.png` 用于页头、个人简介与 favicon，`stormg-banner.png` 用于关于我横幅及分享预览。保留 Storm Studio. 文字品牌；新增图片均由用户提供。

社交图标在 `portfolio_icons.html`，许可记录在 `THIRD_PARTY_ICONS.md`。微信、邮箱弹窗提供复制及复制权限受限时的手动选择，邮箱另有 mailto 入口。关闭脚本仍能看到文字联系方式。

动效逻辑只在公开个人站运行，右下角按钮使用当前浏览器 localStorage 保存开关；系统减少动态效果优先。首页浮动与鼠标反馈、一次性滚动入场都不会阻止导航或内容读取；后台标签页暂停持续动画。演示视频仍由访客手动播放。

## 完整项目档案

作品共10项，AI 工作台为第一项；四个分类为在线工具、个人产品、工程系统、商业项目。移除工具箱介绍页，`/tools` 保留308跳转到工作台详情，实际创作仍通过 `/studio` 登录。

项目的 period、role、description、features 同时供详情、关于我索引和在线简历读取。`profile.json` 保存核心能力、完整工作经历与教育信息。新增项目只需维护这两份公开资料，不能复制租户数据库内容到这里。

visual 显式区分 phones、posters、landscape、browser、concept。概念封面为能力示意，必须保留“非产品截图”标注；补齐真实截图后替换 images 和 visual，并填写实际图片尺寸。六张新增产品图保留用户提供的原始内容。

## 明暗主题与作品优先级

公开个人站提供明暗主题，首次跟随系统，点击页头主题按钮后保存当前浏览器偏好，跨页面与标签页保持一致。初始化脚本先于样式执行，避免已选择深色时闪白；存储被禁用仍能切换当前页面。无脚本时通过 CSS 跟随系统；打印简历固定浅色。原图不反色。

AI 工作台置顶，已有真实截图的项目排列在概念项目之前。Trundertrack 使用用户提供的三张原始界面图，替换概念示意，暂不新增未经确认的链接。大猫商城、易维派按用户要求从公开作品及在线简历移除。
