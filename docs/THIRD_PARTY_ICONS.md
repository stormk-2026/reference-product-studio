# 社交图标

GitHub、X、Telegram、WeChat 图形来自 [Simple Icons](https://github.com/simple-icons/simple-icons)，采用 CC0-1.0，授权文本见 SIMPLE_ICONS_LICENSE.md。下载于 2026-10-22，源路径 `icons/github.svg`、`icons/x.svg`、`icons/telegram.svg`、`icons/wechat.svg`。本地模板仅使用 SVG path，不加载外部脚本或 CDN。

邮箱与动效开关为本站绘制的通用线条图标。头像与横幅为站点所有者提供的原始图片。
