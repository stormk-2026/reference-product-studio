# 简化工作流与验证记录

2026-09-19 更新。已保存升级前数据库备份 `data/before-simple-flows.db`，原素材和历史记录保留。

## 商品解析

上传或拖入、粘贴图片 → 选择逆推提示词 / 白背景实物图 / Beta 三视图 → 补充要求和保留项 → 预览并确认。

一次添加及选择最多 10 张；单张最大 15 MB。每张上传独立校验并保存。上传入口的“来源声明”改为选填图片备注；用户不再需要理解“测试夹具”。开发素材入口收在高级选项，默认隐藏开发测试图片。删除从素材库移除；历史任务引用的原文件保留。

逆推结果默认展示完整 Prompt，支持复制、编辑、保存版本；另一视图显示动态参数，支持单项复制。带入一键混图后，可上传自己的商品并勾选换主体，或加入自己的背景图。完整 Prompt 与参数独立编辑，不会在后台自动互相覆盖。

白底图提取商品，去除周边广告文字和道具。三视图使用正视、侧视、俯视的纯净工业线稿提示词，明确 Beta、不可见结构为假设、无工程精度保证。多张输入作为一次生成的参考，并不自动按图逐张出图；逐张批量使用一键混图。

## 一键混图

按选择顺序处理最多 10 张图。设置换背景 / 换主体，可选自己的背景；换主体必须提供自己的商品图。首张只创建一个任务，其余不会提前调用。

首张不满意：恢复本次设置，补充修改意见，再产生新首张。首张满意：选择通过的候选，预览剩余次数及外发清单，再确认生成剩余图片。每张剩余任务都实际发送通过候选作为最后一张风格参考，要求统一构图语言、色彩和光影，同时保留当前指定商品。

通过候选 ID、原批次图片顺序、参数和风格参考保存在任务快照中，刷新后可从任务记录继续。相同通过候选的剩余任务使用固定幂等键，重复确认不会再次计费提交；失败/未知结果不自动重试。不同修改版首张代表不同批次风格选择，重新通过会建立新的剩余任务。

## 参考重构

添加到“参考图” → 解析参考 → 配方默认收起，可选展开调整 → 保存配方并添加自己的商品 → 生成。

前端自动选择当前参考图的最新配方，无需手动关联分析或配方 ID。配方修改与下一步合并为一次保存操作，避免用未保存的配方生成。还可加入自己的背景图和保留特征。

## 出图后抠图

结果页提供本地 U²-Net 抠图，输出可下载的 RGBA PNG；无需额外服务密钥，不外发图片。已安装 rembg CPU 依赖，固定模型保存在 `data/models/u2net.onnx`；setup 脚本验证上游校验值。运行时使用明确的本地模型路径，缺文件时报错，不偷偷下载模型。首次初始化较慢，之后复用推理 session。

模型来源：[rembg](https://github.com/danielgatis/rembg)、[U²-Net](https://github.com/xuebinqin/U-2-Net)。模型分割仍可能遗漏细杆、半透明壶身和镂空；目前没有交互式涂抹修边。
