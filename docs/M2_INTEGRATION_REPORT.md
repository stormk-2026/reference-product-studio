## 通用商品分析修复

实际首个 Kimi 样例是电喷壶。模型在备注中正确识别商品，但原服装专用字段限制导致属性为空，旧页面又未显示备注。现已取消真实分析的固定服装字段要求：由模型按商品品类生成属性，保持逐字段证据状态与图片来源；摘要和字段说明在页面显示。旧记录保留并标明旧模板，新分析使用通用商品提示词。正背面示意图提示词及工作台文案也改为通用商品；纸样保留为服装专用实验。

空属性结果不再标记成功。新增喷壶、运动鞋、台灯的动态字段协议测试和空结果测试；46 项测试通过。此次修复未再次调用收费模型，动态分析的实际效果待新任务验证。

## 完整提示词与动态参数

通道 A 新增 generation_prompt，真实分析必须返回完整可复制的逆向生图提示词，动态 fields 同时拆解图中商品、构图、配色和光影等实际要素。页面默认全文，支持动态参数切换、逐项复制、全文编辑与版本保存、带入原商品到 AI 换背景。旧分析不伪造完整 Prompt，提示重新分析。两种内容独立编辑，修改参数不会自动重写全文。

B 通道默认 AI 换背景与辅助素材（B2），原图直接编辑，不要求透明图；提示词明确保留商品结构和 Logo 样式，用户可补充保留项。蒙版控件只在 B1 显示。47 项离线测试通过，本轮未发起新的收费生成。

## Seedream Pro HTTP 400 兼容性修复（2026-09-19）

实际混图任务返回 HTTP 400。旧错误处理只保存 HTTP 状态和请求 ID，没有保留供应商错误码，因此无法从旧记录确认完整拒绝原因。核对 [官方图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh) 后发现：Seedream 5.0 Pro 明确不支持配置 sequential_image_generation；旧适配器却发送 disabled，存在确定的协议不兼容。

已移除组图和流式参数，按 Pro 多图融合示例请求单图、明确 PNG 输出；保留 base64 返回要求。新增最多 10 张参考图校验（包括背景、商品和风格样张）。错误响应仅保留受控错误码和参数名，不回显原始错误文字、密钥或 URL。失败混图任务新增“重新载入本次设置”，仍由用户预览确认新任务，不自动重试。

新增协议回归及错误脱敏测试。本轮未再次请求收费生成，修复后的实际成功出图仍待确认。
