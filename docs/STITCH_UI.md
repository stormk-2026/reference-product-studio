# Stitch 设计落地

## 当前版本：玻璃工作台

最新交互按用户截图进一步收敛：Storm Studio. 纯文字品牌，居中页标题，左边缘资产抽屉入口，单个画布生成按钮。白底页为输入与输出两卡；场景页与工业草图页为三卡。上传和作品选择直接进入图片卡弹窗。白底阶段仅一张实拍；多图堆叠只用于混图输入、工业草图补充角度及历史多图记录。工业草图主图1张、补充角度最多5张。呈现要求位于流程下方，比例直接可选，任务状态显示在结果卡。以下初版布局记录仅供追溯。

当前采用用户提供的 Stitch 原型页面（极简玻璃态电商与模特生成工作台）。2026-09-20 读取截图及导出 HTML 后实现。以下旧版本记录只用于追溯。

- 迁移导出代码的浅靛蓝、淡紫、冰蓝渐变背景，半透明白面板，16–20px 背景模糊、细白边框和轻阴影。
- 顶部胶囊导航、左侧窄工具栏、左配置右图片流程、下方真实作品库；资产抽屉随时展开。
- 首页只保留宣传图物料与说明书工业草图两个工具。原型中的模特、虚拟积分、虚构保真率与生成时长不进入生产界面。
- 三张流程卡展示实际商品、参考场景或补充角度、生成结果；未生成时显示空状态。作品库只展示非 Fixture 的 A_white / A_views / B2 候选，点击回填相应参数和图片。
- 商品上传支持本地选择、拖入、粘贴与键盘触发；场景独立选择。白底结果可继续混图或抠图，混图结果不提供抠图。
- 画布按钮与右下固定生成栏共用预览、签名确认和禁用状态；不改模型提示词与批量首张门槛。

实现位于 `static/glass.css`、`static/app.js` 与 `templates/index.html`，没有引入 Tailwind CDN、远程字体、外部脚本或示例图片，保持原有 CSP。窄屏采用单列响应式样式。

浏览器核对了首页、真实作品回填、白底接续场景、工业草图预览、确认展开与勾选保持有效；桌面无横向溢出。预览后取消，未产生额外收费生成；未声称完成真机测试。

## 早期版本记录

来源：用户提供的 Stitch 原型项目（直观美学控制面板），页面“AI电商商品智能生成与反推工作台”。2026-09-20 实现。

## 视觉与交互映射

- 左侧白色商品资产栏、纵向缩略卡片、黑色细边框选中态；可选主要参考图片。设为主图会更新真实输入顺序，多角度模式以该图为主体依据，批量模式以该商品先试图。
- 右侧路线卡片及四步配置：操作路线、场景设置、创意要求与保真、画布与执行。
- 顶部 EcomAI Studio 品牌与历史作品入口；保留本地单用户属性。
- 新版“极简精工版”的中性黑白、浅灰底、细边框卡片、纯黑主按钮，绿色仅用于状态及焦点反馈；窄屏改为单列，素材区可滚动。
- 结果及历史位于配置区下方，保留全部真实记录、人工评价、复用、导出与批量确认功能。

原型中的虚拟余额、充值、虚构引擎版本、采样器、CFG、固定种子、微距修复等未接入控件不展示。图片上传仍只保存本地，不自动进行收费分析。没有引入 Tailwind CDN、第三方图标脚本或远程字体；样式与图标本地实现，保留原有 CSP。

## 验证

65 项离线测试通过、Ruff 与 JavaScript 语法检查通过。浏览器验证主要参考选择、商品/场景预览、详情展开与勾选不收起、三条路线切换、说明书草图文案及历史入口；桌面无横向溢出。没有额外付费生图。未改动已验证的模型提示词、授权签名、任务幂等和批量门槛。

## 连贯操作更新

进一步按极简精工版落地说明型大卡片、快捷风格按钮及比例选择。白底实物图结果可直接带入混图；任何真实图像结果可打开本地宣传排版，提供三种基础版式、标题与卖点编辑、PNG 下载。参考配方路线保留，宣传排版位于结果区。

浏览器验证：A 白底模式卡片切换；已有白底结果成为 B2 唯一输入且在素材栏可见；场景重选；宣传文案实时预览、版式切换及下载按钮。未触发新的收费生成。

## 两工具版工作区（当前版本）

首页改为宣传图物料、说明书工业草图两个入口。保留中性配色和卡片层级，资产为左侧抽屉，工作区仅显示所选流程，底部生成栏固定。宣传图白底结果可直接接续场景混图或抠图下载；混图及工业草图不展示抠图。旧逆推、配方和文字排版入口退出当前界面。

## 批量样张决策

批量第一张出图后，完整商品堆叠仍保留；画布下方增加样张确认面板，展示每个商品的缩略图与生成状态。通过后预览剩余调用，不满意则保留完整批次和场景编辑要求。决策期间隐藏通用生成入口，避免重复创建首张。已提交的子任务按通过样张分组追踪。

## 结果区整合

取消页面底部独立“生成结果”大栏。生成状态与常用操作集中在右侧结果卡，批量确认紧邻流程卡；记录、对照、评价、收藏及追溯导出放入“详情 · 记录与评价”弹窗。历史作品亦复用该工作区，旧分析类任务在详情中查看。
