## 2. A：服装逆向与技术资料

输入一张或多张服装图及用户补充的正背面关系、尺寸、材质、工艺、要求。

分析包含类别、轮廓、领型、袖型、门襟、口袋、下摆、可见图案、拼接与装饰、遮挡区域和待补信息。每项标记 `user_confirmed / observed / inferred / unknown`，保留证据资源与用户修正。`observed` 是模型判断，不是已验证事实；模型自报置信度不作为校准概率。

输出正面/背面技术款式图候选与技术资料初稿。已确认信息、图像观察、设计推测、待确认项分开；尺寸、工艺表可编辑，未知尺寸留空并标未知。缺少背面图时背面固定标为“设计假设”，不能标为还原。

独立实验入口生成纸样形态探索示意，页面、结果说明与导出中永久显示：**未经版师验证，不可直接裁剪生产**。不编造测量、放码、缝份或 CAD 能力；无模型能力时明确显示不支持，不创建空文件占位。A 不以工厂可生产或精确纸样为验收标准。

## 3. B：商品素材编辑与重制

本地上传商品图、编辑要求，可选蒙版或透明图。提供背景移除或透明图替代路径、背景替换、场景重渲染、比例与留白、光影协调、原图对照、本地收藏、下载及关键特征人工检查。

- **B1 主体保留合成**：优先用户透明图或有效分割蒙版，生成背景后确定性合成。支持位置、缩放、边缘处理；重采样、调色、光照处理必须写入记录。不宣称像素绝对不变，不生成不存在的商品视角。缺少自动分割能力时明确引导上传透明图/蒙版，不能伪装已抠图。
- **B2 生成式重绘**：模型可改变场景和光影；界面提示商品细节可能变化，不保证 Logo、文字、纹理、纽扣或轮廓准确，始终保留原图对照。

不爬取电商平台，不去水印，不规避相似度检测，不宣称获得版权或必然不侵权；默认仅本地保存。

## 4. C：参考解析与场景重构

输入商品图、参考图、商品保留项、希望借用的视觉元素。

- **C1 直接参考基线**：商品图 + 原参考图 + 简短要求 → 图像编辑模型。
- **C2 可控重构**：参考分析 → Scene Recipe → 各元素继承/修改/忽略 → 请求编译 → 图像编辑 → 三图对照 → 人工评价。

Recipe 包含场景类型、主体位置与占比、机位类别、留白、光源方向、软硬、对比、背景颜色/材质、道具类别/相对位置、色彩关系、景深、商品保留项、禁止带入元素。摄影信息标为视觉估计，允许 unknown/null，不推造精确焦距、角度或测量。

C2 支持“原参考图 + 结构化约束”及明确选定的“仅文字配方”策略，不强制丢弃原图。能力不足必须阻止请求并说明，不能静默降级。支持保存/复用配方、修改单项再生成、C1/C2 可比对照；记录失真、参考符合度、可用性、人工返工。可控性不等于图像质量更优。

## 6. 任务与安全

持久化 Job + 独立 Worker，真实生成不占用长同步 Web 请求。幂等提交防重复付费；区分 failed、interrupted、outcome_unknown；超时不代表未生成。未知结果不自动重新付费；只有供应商支持查询时才恢复查询，人工重试先提示重复费用风险。

验证 Host/Origin，适用的 CSRF 防护；检查上传字节数、MIME 与实际解码格式、像素数；随机 ID、路径安全、资源下载白名单。模型输出与图中文字均不可信。供应商结果 URL 仅按明确的允许来源下载，限制跳转、体积及内网访问。临时文件与完整资源分开。
